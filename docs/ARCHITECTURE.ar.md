# GoodAI Sentinel — المخطط المعماري

**الهدف:** وحدة ذكاء اصطناعي دفاعي مفتوحة وقابلة للتضمين تحمي الحواسيب والشبكات والأجهزة والبرمجيات من السلوك غير المصرّح به أو التخريبي — أياً كان الفاعل: إنساناً، برمجية خبيثة، أو وكيل ذكاء اصطناعي أو نموذجاً أو روبوتاً.

**ليس الهدف:** نموذجاً واحداً يعرف كل شيء. الدفاع الذي ينجح يكون *متعدد الطبقات*، *قابلاً للتفسير*، و*يفشل بأمان*. مهمة الذكاء الاصطناعي هي الرؤية عبر الطبقات، والاستدلال على النية، والتصرف ضمن حدود صارمة.

---

## 1. مبادئ التصميم

| المبدأ | المعنى عملياً |
|---|---|
| **المنع افتراضياً** | الوكيل لا يفعل إلا ما تمنحه سياسته صراحةً. المجهول = مرفوض. |
| **القابل للتراجع أولاً** | سلّم الاستجابة: تسجيل ← تنبيه ← تبطيء ← تجميد (SIGSTOP) ← إنهاء ← حظر. جمّد قبل أن تقتل؛ هذا يحفظ الأدلة الجنائية. |
| **الإنسان في الحلقة** | الإجراءات غير القابلة للتراجع أو عالية الأثر تحتاج موافقة. الاستقلالية اختيارية ومقيّدة بالخطورة. |
| **قابل للتفسير** | كل اكتشاف يستشهد بقاعدة أو بدرجة غرابة؛ كل قرار يستشهد ببند السياسة. لا أحكام من صندوق أسود. |
| **مقاوم للعبث** | سجل تدقيق بسلسلة تجزئة؛ ملف السياسة وكود Sentinel نفسه في قائمة المنع لكل وكيل. |
| **لا تتعلّم من الهجمات أبداً** | خط الأساس السلوكي يتعلّم فقط من الأحداث التي *لم* يبلّغ عنها، فلا يمكن تدريبه على قبول اختراق. |
| **مفتاح الإيقاف** | قيمة منطقية واحدة تجمّد كل أفعال الوكلاء في النظام كله. |
| **لا يمكن للمحميّ منه أن يعطّل الدفاع** | `forbidden_patterns.disable_defense` و`self_modify` يُفحصان قبل الصلاحيات — لا وكيل، مهما علت صلاحياته، يستطيع إيقاف Sentinel عبر Sentinel. |

## 2. طبقات النظام

```
┌──────────────────────────────────────────────────────────────────┐
│  L6  الحوكمة        سياسة YAML · واجهة موافقات · مفتاح إيقاف    │
├──────────────────────────────────────────────────────────────────┤
│  L5  الاستدلال      فرز بنموذج لغوي (اختياري) · كتيّبات · تقييم │
├──────────────────────────────────────────────────────────────────┤
│  L4  الاكتشاف       قواعد · خط أساس سلوكي · نماذج تعلّم آلي     │
├──────────────────────────────────────────────────────────────────┤
│  L3  الحاجز         نطاق الصلاحيات · الأهداف · المعدّل · الميزانية│
│                     · الأنماط المحظورة · بوابات الموافقة         │
├──────────────────────────────────────────────────────────────────┤
│  L2  المستشعرات     العمليات · الشبكة · سلامة الملفات · أفعال   │
│                     الوكلاء · (خارجي: syslog, eBPF, سجلات سحابية)│
├──────────────────────────────────────────────────────────────────┤
│  L1  الإنفاذ        SIGSTOP/kill · iptables · nice · sandbox      │
│                     · فضاءات شبكة · إيقاف الحاويات               │
├──────────────────────────────────────────────────────────────────┤
│  L0  التدقيق        JSONL بسلسلة تجزئة · تصدير إلى SIEM         │
└──────────────────────────────────────────────────────────────────┘
```

### تدفق البيانات

```
 المستشعرات ──Event──▶ الكاشف ──Finding──▶ المستجيب ──▶ الإنفاذ
                                                │
 وكيل الذكاء ──request()──▶ الحاجز ──Decision───┤
                                                ▼
                                           سجل التدقيق
```

نقطتا دخول:

1. **المراقبة السلبية** (`Sentinel.tick()` / `run()`): المستشعرات تراقب الجهاز، الكاشف يقيّم الأحداث، المستجيب يتصرّف ضمن سلّمه.
2. **اسأل قبل أن تفعل** (`Sentinel.request(agent_id, action, target)`): أي وكيل ذكاء اصطناعي يقدّم فعله المقصود *قبل* تنفيذه ويحصل على `allow` أو `deny` أو `require_approval`. هذه هي "وحدة الذكاء الاصطناعي التي يستخدمها الجميع" — فحص إذن عام للأنظمة المستقلة.

## 3. مرجع المكوّنات

### المستشعرات (`sentinel/sensors.py`)
- `ProcessSensor` — يقارن جدول العمليات؛ يُصدر `new_process` / `process_exited` مع سطر الأوامر والملف التنفيذي والمستخدم والأب.
- `NetworkSensor` — المقابس الجديدة؛ `outbound_conn` / `listening_port`.
- `FileIntegritySensor` — SHA-256 للمسارات المراقبة؛ `file_created/modified/deleted`.
- `AgentActionSensor` — طابور لنوايا وكلاء الذكاء الاصطناعي.
- **نقاط التوسّع:** غلّف أي مصدر سجلات (syslog، journald، سجلات التدقيق السحابية، eBPF، قياسات الروبوتات، حركة PLC/SCADA) في صنف له دالة `poll() -> Iterator[Event]`.

### الكاشف (`sentinel/detector.py`)
- **القواعد** (دقة عالية): التنزيل والتنفيذ، الأصداف العكسية، مسح الأقراص، `rm -rf /`، التنفيذ من `/tmp`، تصعيد الصلاحيات، تغييرات الملفات الحساسة، منافذ C2، التغيير الجماعي للملفات على نمط برامج الفدية، أفعال الوكلاء الخطرة.
- **خط الأساس** (استدعاء للمجهول): نموذج تردد لكل خاصية — الغرابة = 1 − p(شوهد). يتعلّم أثناء الإحماء ومن الأحداث غير المبلَّغ عنها فقط. قابل للتفسير، بلا بيانات تدريب. استبدله بغابة عزل / مشفّر ذاتي / نموذج تسلسلي عبر واجهة `score()` نفسها حين تتوفر البيانات.

### الحاجز (`sentinel/guardrail.py` + `policy/agent_guardrails.yaml`)
ترتيب التقييم (أول تطابق يحسم):
1. مفتاح الإيقاف
2. الأنماط المحظورة (تعطيل الدفاع، التعديل الذاتي، تدمير البيانات، التسريب، الصدفة العكسية، تصعيد الصلاحيات، الوصول للاعتمادات، التكاثر الذاتي غير المحدود، كتابة البرامج الثابتة، تدمير السجلات)
3. نطاق الصلاحيات (`read:*`، `write:file`، `deploy:*` …)
4. نطاق الأهداف (أنماط `allow_targets` / `deny_targets`)
5. حد المعدّل لكل وكيل
6. الميزانية لكل وكيل (تكلفة/رموز/أي وحدة)
7. بوابات الموافقة للأفعال غير القابلة للتراجع
8. السماح

يُطابَق الوكلاء بأنماط على `agent_id` (`coder-*`، `ops-*`، `untrusted-*`)، ويرثون `defaults`.

### المستجيب (`sentinel/responder.py`)
- الخطورة تحدّد سقف الاستجابة التلقائية: `medium/high → alert`، `critical → isolate`. ما يتجاوز السقف يُدرج في طابور الموافقة البشرية ما لم يكن `autonomous=True`.
- `dry_run=True` افتراضياً: لا شيء يلمس الجهاز حتى تمرّر `--live`.
- `AuditLog`: إلحاق فقط، كل سجل يجزّئ السابق — `verify()` يكشف أي تعديل.

## 4. طبولوجيات النشر

| النطاق | الإعداد |
|---|---|
| جهاز واحد | `python -m sentinel --watch /etc /home/me --live` كخدمة systemd |
| أسطول | Sentinel لكل مضيف، أرسل JSONL التدقيق إلى مجمّع مركزي (SIEM/OpenSearch)؛ مستودع سياسة مركزي بملفات YAML موقّعة |
| منصة وكلاء ذكاء اصطناعي | ضمّن `Sentinel.request()` كوسيط في مسار استدعاء الأدوات لإطار الوكلاء (LangChain/LangGraph/AutoGen/بوابة MCP). كل استدعاء أداة = `request()` واحد. |
| الروبوتات / إنترنت الأشياء | محوّلات مستشعرات لأوامر المحركات والسياجات الجغرافية وكتابة البرامج الثابتة؛ قواعد حاجز للحدود الفيزيائية (السرعة، القوة، المناطق)؛ الإنفاذ = مرحّل إيقاف طارئ |

## 5. تغطية نموذج التهديد

| التهديد | الطبقة التي تلتقطه |
|---|---|
| تنزيل برمجية خبيثة وتنفيذها، صدفة عكسية | القواعد (العمليات)، منفذ C2 (الشبكة) |
| برامج الفدية | التغيير الجماعي للملفات + قواعد الملفات الحساسة |
| مطّلع داخلي / اعتمادات مسروقة | غرابة خط الأساس (مستخدم جديد، أب جديد، وجهة جديدة) |
| وكيل ذكاء مارق: يسرّب الأسرار | الحاجز `exfiltrate`، `credential_access`، deny_targets |
| وكيل ذكاء مارق: يعطّل الدفاعات / يعدّل نفسه | الحاجز `disable_defense`، `self_modify` (يُفحص أولاً، لا يمكن تجاوزه) |
| وكيل ذكاء مارق: حلقات جامحة / تكاثر ذاتي | حد المعدّل، الميزانية، `spawn_unbounded` |
| تعطيل البرامج الثابتة / العتاد | `control_hardware`، `destroy_data` |
| العبث بالسجلات | تدقيق بسلسلة تجزئة + نمط `disable_logging` |
| حقن أوامر يوجّه وكيلاً | الحقن لا يمنح صلاحيات لا تمنحها السياسة — الأفعال تمرّ عبر الحاجز على أي حال |

## 6. قائمة التحصين قبل الإنتاج
- شغّل Sentinel بمستخدم مخصص منخفض الصلاحيات يملك فقط ما يحتاجه الإنفاذ (`CAP_KILL`، `CAP_NET_ADMIN`).
- اجعل `policy/` و`sentinel/` للقراءة فقط (سمة عدم التغيير، إصدارات موقّعة).
- أرسل سجل التدقيق خارج المضيف في الزمن شبه الحقيقي.
- أضف قناة موافقات (Slack/PagerDuty/بريد) كدالة `approver`.
- استبدل قواعد التعبيرات النمطية بمكتبة اكتشاف مُصانة (قواعد Sigma) وخط الأساس بنموذج مدرّب بعد توفر ≥ أسبوعين من البيانات السليمة.
- اختبره بفريق أحمر: راجع `RESEARCH_PLAN.ar.md` §4.

## 7. مستويات زمن الاستجابة لـ `request()` على المسارات الساخنة

| المستوى | متى | الآلية | التكلفة |
|---|---|---|---|
| 1 تصريح واحد | حلقات عالية التردد (مطابقة، كتابة دفعية، حلقات تحكم) | `grant()` ← رمز صلاحية موقّع؛ `validate()` داخل العملية | ≤ 1.5 ميكروثانية |
| 2 متزامن سريع | فحص لكل عملية لا مفر منه، والعملية 1 ملّي ثانية+ | `request()` مع `async_audit=True`؛ القرار في الذاكرة، التدقيق عبر كاتب خلفي | ~40 ميكروثانية |
| 3 الظل | العملية لا تحتمل 40 ميكروثانية **وهي قابلة للتراجع** | القرار يجري بالتوازي مع العملية؛ المنع ← إلغاء التصاريح + تراجع | 0 على المسار |
| 4 نافذي | التدفقات / تغذيات المستشعرات | تقييم نوافذ 100 ملّي ثانية؛ الإنفاذ بعدم تجديد الرموز | مُستهلَك تدريجياً |

القواعد: الأفعال غير القابلة للتراجع لا تستخدم المستوى 3 أبداً؛ انتهاء مهلة الحاجز يفشل *مغلقاً* للأفعال غير القابلة للتراجع و*مفتوحاً مع ظل* للقابلة للتراجع. الغرابة تشكّل التصريح (العدد × (1 − الغرابة)، والمدة كذلك)، فالحلقة الساخنة لا تقيّم الغرابة أبداً.
